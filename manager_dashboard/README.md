# Manager Dashboard

React + TypeScript + Tailwind CSS v4 (Vite)

```bash
cd manager_dashboard
npm install
npm run dev      # http://localhost:5173
```

ค่า environment อยู่ใน `.env` (คัดลอกจาก `.env.example`)

| ตัวแปร | ค่า |
| --- | --- |
| `VITE_API_BASE_URL` | URL ของ FastAPI บน AWS (`.../api/v1`) |
